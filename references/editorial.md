# 内容编辑

## 从材料到阅读顺序

选择一个能贯穿全套的核心问题，判断读者需要先理解处境、看见差异，还是先获得方法。可重排材料、合并重复论点、增加解释框架；不得把所有生活故事都改成教程。

常用表达单元包括具体情境、判断、理由、例子、步骤和收束。根据材料选择单元，无固定八页公式；4–8 页是默认范围而非必须凑齐的任务。页数与用户要求冲突时先遵循用户要求，必要时说明信息取舍。

## 哪些内容需要确认

| 内容变化 | 处理 |
| --- | --- |
| 精简、分段、重排、同义标题 | 直接处理 |
| 为已有材料命名或整理建议性框架 | 直接处理，明确其为编辑建议 |
| 提出原材料没有的主要结论 | 展示拟用表述，请用户确认 |
| 关键数据、产品参数、案例依据缺失 | 请求材料、核实或删去，不能猜测 |
| 与用户明确观点不同的新立场 | 先确认，不能擅自替换 |

只因输入没有逐项回答受众、目标等字段，不足以要求用户填写整份问卷。可合理推定的非关键事项简短说明即可。

## 表达语气

自然、亲切，并理解读者的处境。用具体情境引出有依据的观点；可以坚定，但不替读者断言感受、不说教、不虚构第一人称经历。专业术语必要时用一句易懂的话解释。

封面兼顾共鸣与观点，选择一个主要阅读理由；两者不需要强行同时出现。避免“必看”“绝绝子”等口号、过多感叹号与夸张营销表达。内页必须兑现封面承诺。

每页通常用一个重点加 2–4 条短解释，或一个充分的例子；不为凑条目制造废话。内容拥挤时先删重复，再考虑拆页，不以缩小字号作为默认解法。

结尾默认自然总结或留有余韵。仅当有帮助时加入一个交流问题或小行动，不机械要求点赞、收藏、关注。明确的商业目标由用户本次要求决定。
