# 设计语言

## 共同骨架

以浅色底、清楚分区和有节制的重点标记建立知识卡片气质。每套确定背景、主文字、辅助文字和一种强调色，强调色根据主题与素材选择，不固定品牌色。

保持字体组合、边距、组件样式一致，构图允许变化。教程结构更稳定，故事或共鸣内容可有更明显的场景与留白变化，不机械交替页型。

排版起点：3:4 竖版，参考 1080×1440；四周留出约画布短边 6%–8% 的安全区域。字号和间距按实际尺寸与字数确定。实际缩小到手机阅读大小后检查；不把单一字号当成所有内容的硬标准。

## 依内容做选择

| 元素 | 选择依据 |
| --- | --- |
| 字体 | 工具与方法优先清晰黑体；生活感悟可用柔和字体或宋体标题；正文始终易读 |
| 封面 | 观点突出标题；方法采用图文分区；共鸣可用场景主视觉 |
| 图解 | 模块卡片为主，流程与关系配线条、箭头；手绘标注只在有助理解时使用 |
| 插画 | 方法偏简洁扁平，感悟偏温暖手绘，具体情境可用自然写实 |
| 实物素材 | 案例保留上下文，操作截图突出细节，产品突出主体 |

这些对应关系是决策参考，不是强制匹配。整套确定一种主要插画语言和固定字体组合；真实截图无需强制改色来匹配插画。

## 素材处理

照片、截图和产品图按用途采用原貌展示、细节放大或卡片容器。裁切不能改变事实含义，箭头应有明确指向，放大细节应能对应原图。不得用生成场景冒充实拍或用生成界面冒充实际操作证据。

缺少必要素材时索取最关键的一项，或使用明确标识的示意，不擅自下载来源不明的图片或字体。发现截图中无关的身份与联系方式时，在对外成品中遮挡。

## 完成前的视觉检查

- 标题是否清晰，重点是否只有少数几处，颜色对比是否够用。
- 文案是否准确，是否有乱码、漏字、遮挡或被裁切。
- 卡片是否对应信息分组，连线是否对应真实关系。
- 系列是否保持共同语言，同时有内容所需的阅读节奏。

正常的大标题不等于夸张营销；避免的是用失衡尺寸与空泛口号掩盖信息。用户并未普遍禁止 emoji、卡通或渐变，不新增无依据的禁用清单。
