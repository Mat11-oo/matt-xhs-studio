# 使用与维护说明

维护者：matt。版本：0.1.0 预览版。许可：[MIT](../LICENSE)。

## 安装与调用

需要支持 SKILL.md 的宿主。下载并解压，将整个 matt-xhs-studio 文件夹导入宿主技能目录或通过本地技能加载功能选择该目录。不要只复制 SKILL.md；references 和 templates 必须随目录保留。导入操作以所用宿主的说明为准。

支持美元符号调用时使用 `$matt-xhs-studio`。提供主题、受众、目标与已有素材，只有关键信息不足时才需要澄清。首次默认生成一张样图，确认后完成全套；明确要求跳过样图可直接制作。只需要规划或提示词时直接说明。

## 默认工作方式

深度策划，通常 4–8 页，浅色知识卡片，每套一种强调色。文字自然、温暖、适中；封面结合情境共鸣与有依据的观点。配图结合模块图解、场景插画和真实素材。首次风格确认后，通过可访问的项目风格记录复用。明确的局部修改直接执行，不重复审批。

## 自定义入口

- [SKILL.md](../SKILL.md)：默认页数、交付、沟通和执行路径。
- [内容编辑](../references/editorial.md)：语气、策划与关键内容确认。
- [设计语言](../references/design.md)：配色、字体、图解、插画、封面及页面节奏。
- [制作与交付](../references/production.md)：工具失败处理、实际图片检查和文件组织。
- [项目记录](../templates/project.md)：项目记录字段。
- [界面元数据](../agents/openai.yaml)：展示名、简介和启动提示。

## 当前状态

技能不内置图片生成模型、API 密钥、字体或跨对话记忆。没有图片能力时，只能交付规划与提示词，不虚构完成状态。实际尺寸和中文排版依赖宿主工具。

当前版本尚无成功的端到端图片生成验证。README 图片是项目说明与版式示意，不是工具生成的成品案例。结构验证不能证明行为或画质已稳定。
