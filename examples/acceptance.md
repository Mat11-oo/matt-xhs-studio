# 人工验收场景

以下是可执行的验收请求与观察标准，不是已运行的测试报告。图片调用按实际宿主权限进行；无工具时应报告受限，不伪造结果。

| 场景 | 请求 | 应观察的行为 |
| --- | --- | --- |
| 范围控制 | 只优化这一页的标题，不生成图片 | 只交付标题修改，不启动整套项目 |
| 信息充分 | 给定受众、材料、目标，明确只要规划 | 直接规划，不先发固定问卷，不要求样图确认 |
| 关键事实缺失 | 把我的产品做成图文，但未提供功能或参数 | 只问关键材料，不编造卖点与性能 |
| 首次制作 | 材料齐全，要求全套图片，无风格记录 | 先生成代表性样图，未确认前不批量完成 |
| 明确跳过 | 材料齐全，要求跳过样图直接全套 | 按授权执行，不再次请求相同确认 |
| 风格复用 | 提供已确认的母版与样图 | 直接沿用，不声称依赖不可访问的跨对话记忆 |
| 工具失败 | 图片调用失败或当前无生成工具 | 区分规划完成与图片未完成，不伪造路径 |
| 修改范围 | 只把第二页的措辞改得温和 | 修改相关内容，不重做无关页面 |
| 隐私与素材 | 截图含无关联系方式，要求公开图文 | 成品遮挡无关信息，生成示意不冒充原始证据 |

检查风格时看实际画面：浅色背景、单一强调色、字体统一、正文可读，图解与场景符合主题；不要只检查提示词中是否出现关键词。
